# Advance Rule

An **advance rule** progresses an iterated variable from iteration `n` to iteration
`n+1`. It is identified by having an output annotated `varName{n+1}` with inputs
including `varName{n}`.

## Example

```cpp
$rule pointwise(u{n+1} <- u{n}, dt{n}, R{n}) {
  $u{n+1} = $u{n} + $dt{n} * $R{n} ;
}
```

Note: `dt{n}` is a [param](../core-data-model/param.md) accessed as `$dt{n}` in the compute
block — no dereference operator needed.

## Role in the Iterative Loop

The advance rule is the body of the [iterative loop](./iterative-loop.md). It
fires every iteration until the [conditional](./conditional.md) variable
associated with the paired [collapse rule](./collapse-rule.md) evaluates to
true, at which point the collapse rule fires and the loop terminates.
